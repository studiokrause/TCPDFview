# TCPDFview

Total Commander Lister & Thumbnail Plugin for PDF files.

## Description / Opis
- **Autor:** Studio Krause / gemini-flash-lite-latest
- **Wersja:** 0.1
- **Licencja:** AGPL (ze względu na dołączoną bibliotekę Ghostscript)

## Features / Funkcje
1. **Podgląd PDF w listerze:**
   - Dopasowanie wielkości strony do okna klawiszem `0` oraz `*` (normalna i numeryczna klawiatura).
   - Powiększanie/zmniejszanie przez `+` i `-`.
   - Przesuwanie strzałkami (o kilka wierszy) oraz `PgUp` / `PgDown` (o całą stronę, `PgDown` do kolejnej).
   - `Esc` - zamknięcie.
   - `Enter` - przejście do pliku w Total Commanderze.
   - `Shift+Enter` - przejście do pliku w Eksploratorze Windows.
2. **Miniatury PDF:**
   - Wyświetlanie miniatur PDF w widoku miniatur.
3. **Cache miniatur:**
   - Automatyczne tworzenie cache miniatur istniejących plików PDF przy włączaniu widoku.
   - Weryfikacja zmian pliku PDF.
   - Opcja w menu pod prawym przyciskiem: "Wyczyść cache".
4. **Ghostscript:**
   - Dołączony dystrybucyjny Ghostscript DLL w pakiecie instalacyjnym.
5. **Menu kontekstowe:**
   - Wszystkie polecenia dostępne w menu prawego przycisku myszy.
   - Pozycja "O programie" w ostatnim elemencie menu wyświetlająca informacje o autorze, wersji i licencji AGPL.
6. **Wersje językowe:**
   - Obsługa 6 języków: PL, EN, DE, FR, ES, IT.
